# 📦 FileDrop – File Hosting Server

## كيفاش تشغل المشروع

### المتطلبات
- Node.js مثبت على جهازك → https://nodejs.org

### الخطوات

```bash
# 1. فك الضغط وافتح المجلد
cd file-host

# 2. ثبّت المكتبات
npm install

# 3. شغّل السيرفر
npm start
```

### بعد التشغيل
افتح المتصفح على:
👉 http://localhost:3000

---

## كيفاش يخدم؟

1. **ارفع فايل** من الواجهة
2. **احصل على رابط** مثل: `http://localhost:3000/download/abc123.pdf`
3. **أي شخص** في نفس الشبكة يقدر يحمل من الرابط

---

## API Endpoints

| Method | URL | الوصف |
|--------|-----|-------|
| POST | `/upload` | رفع ملف |
| GET | `/download/:filename` | تحميل ملف |
| GET | `/files` | قائمة كل الملفات |

## ملاحظات
- الملفات تتخزن في مجلد `uploads/`
- الحد الأقصى: 100 ميغابايت
- لتشغيل الرابط على الإنترنت: استخدم ngrok أو نزّل على VPS
